# Demonstration photographs: credits and licences

These demonstration photographs are third-party assets and are not covered by the TowerGuard application's code licence. Their respective licences continue to apply.

They are included only so that TowerGuard can be demonstrated with realistic tower imagery. They are **demonstration assets, not verified photographs from a TowerGuard field inspection**. Any annotations, observations or findings recorded on them in a demonstration are illustrative and are not statements about the condition of the structures shown.

Each file below is the photographer's original JPEG, **copied byte-for-byte; only the filename was changed**. No file has been resized, recompressed, rotated, cropped or edited, and embedded EXIF metadata is preserved. The SHA-256 hash of each committed file is recorded so that it can be checked against the hash TowerGuard shows after upload.

The photographs are uploaded manually through the normal inspection workflow; the application does not load, bundle or serve them. See [../demo-checklist.md](../demo-checklist.md) for how to use them in a demonstration.
